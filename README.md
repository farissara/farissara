#  About Me  
 Hello, I am **Faris Sara**, a **MSc Cyber Security Student at University of the West of England (UWE Bristol)** and a **First-Class BSc (Hons) Computer Science Graduate** from **UWE Bristol**.  

I am passionate about developing intelligent **AI-powered systems** and automating challenging tasks.  Some of my projects involve developing smart assistants and **chatbots** and creating strong backend services that make workflows easier.  I really enjoy using machine learning to solve problems in the real world, and I often use **Python** (which has a lot of ML tools) and **JavaScript** to make these ideas come to life.  I love learning about new technologies and coming up with creative ways to solve problems.
